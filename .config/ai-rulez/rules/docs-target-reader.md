There are 2 kind of target reader for docs, AI agent and human. When writing docs for AI Agents (especially in `.config/ai-rulez/**`), direct and conscise communication style for saving token is more important and storing git repository URL prefered over website. When writing docs for human (especially in `**/README.md`), natural and easy to understand communication style is more important and storing website URL prefered over git repository.

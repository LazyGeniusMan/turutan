# turutan template

This is a project template generated by [`turutan`](https://github.com/LazyGeniusMan/turutan/commits/main/) that include many profiles. Each profiles is preconfigured to install toolchains and git hooks, it will also setup relevant AI Agents skills, rules, and MCPs if `ai` profile is enabled.

## Prerequisite

* [`mise`](https://mise.jdx.dev) is installed and `mise doctor` command return no problems found.

## Profiles

Configure active profiles in [`.config/miserc.toml`](.config/miserc.toml). Available profiles are:

### Universal

* `core`

    [`mise`](https://mise.jdx.dev) as toolchain, dependencies, and task runner manager; [`hk`](https://hk.jdx.dev) as git hooks manager that configure linter, formatter, etc; [`pitchfork`](https://pitchfork.jdx.dev) as background process manager; [`fnox`](https://fnox.jdx.dev) as secret manager. [Proton Pass](https://proton.me/pass) is preinstalled and preconfigured as secret provider.

* `ai`

    [`ai-rulez`](https://github.com/Goldziher/ai-rulez) as centralized AI Agents configuration, rules, skill, and mcp manager; [`basemind`](https://github.com/Goldziher/basemind) as codebase context indexer; [`uncomment`](https://github.com/Goldziher/uncomment) as codebase comments removal. [`pi`](https://pi.dev) and [T3 Code](https://t3.codes) Web UI is preconfigured as AI Agent; add other AI Agents by adding it to [`.config/mise/config.ai.toml`](.config/mise/config.ai.toml).

## Setup

### First Time
1. Install project dependencies
```sh
mise trust && mise install
```
2. Setup global provider to store remote secret provider PAT, for example 
```sh
fnox provider add global keychain -g # or `fnox provider add global plain -g` if os keychain is not available (insecure)
fnox set PROTON_PASS_PERSONAL_ACCESS_TOKEN --provider global -g
```
3. Configure dependencies
```sh
mise run dev-setup:**
```

### Development
```sh
mise run dev:**
```

### Polygot FFI Binding
```
mise bootstrap package install
```
